# 数据与权限

当前版本：0.1.0。此说明描述当前代码的行为，不代表未来版本自动获得更多授权。

## 本地处理

- 工具不设自建服务端、追踪统计或云端同步。
- 在用户点击扩展后读取当前微博登录账号的 UID、昵称、简介和主页统计等资料。
- 采集时使用微博页面原有的登录状态发送只读请求，不提取密码、Cookie 或验证码。
- 博文、原始响应和采集断点保存在扩展自己的 IndexedDB，按账号 UID 隔离。
- 用户选择导入的 JSON 在本地解析、去重；导出文件由 Chrome 保存到本机。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| activeTab | 用户点击图标后临时访问当前微博标签页 |
| scripting | 执行随扩展打包的账号识别与只读采集程序 |
| storage | 保存连接的标签页和工作台信息 |
| unlimitedStorage | 存放较大档案，仍受设备空间限制 |
| downloads | 生成并下载 JSON 和 HTML |

没有 Cookie 读取权限或所有网站的常驻访问权限。不加载远程执行代码。

## 在线媒体与外部链接

打开档案阅读器后，头像、封面、配图和视频可能访问接口返回的在线媒体服务。服务方会收到该请求及 IP 等网络信息。点击原微博或其他链接会打开对应网站。

文字和阅读脚本已经嵌入导出 HTML；媒体文件尚未离线下载，在线地址可能过期。

## 保存与删除

请妥善保管导出 JSON 与 HTML，它们可能包含仅自己可见的博文。不要把个人档案上传到公开仓库或公开 Issue。

卸载扩展或清除 Chrome 用户配置可能删除扩展本地数据库；保存到本机的导出文件不随卸载自动删除。不同 Chrome 配置间不会自动同步档案。

## 访问范围

只备份当前登录账号仍可读取的内容，不绕过验证码或平台访问权限。第一版未采集评论正文、未补全长文、未离线下载媒体。账号异常或访问受限时停止请求，由用户在微博自行处理。
