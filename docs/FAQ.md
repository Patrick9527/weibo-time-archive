# 常见问题

### 我只有手机，能直接安装吗？

当前版本面向电脑端 Chrome。暂不提供微信小程序、手机 App 或移动浏览器安装流程。

### 为什么不能直接打开 index.html？

它是扩展工作台，需要 Chrome 扩展 API。必须在 `chrome://extensions` 加载，然后点击扩展图标启动。导出的个人档案 HTML 则可以独立打开。

### 是不是下载源码后还要运行服务器？

不用。下载成品 ZIP 后解压即可加载；下载源码 ZIP 后，选择 `extension` 文件夹加载即可。Node.js 和 Python 仅供开发测试、重新打包使用。

### 为什么没有连接到账号？

确认在电脑端 `https://weibo.com/` 登录，并在那个微博标签页点击扩展。只打开工作台不会自动获得微博访问权限。如果刷新或切换账号，请重新在微博页面点击图标连接。

### 能备份封禁账号吗？

取决于该账号在本人登录后是否仍能从接口读取历史博文。可以读取的内容有机会备份；服务器拒绝提供的内容无法通过本工具恢复。

### 数量和微博总数不一样怎么办？

接口的历史范围、删除、可见性和分页限制可能造成差异。请比较时间覆盖和实际记录。本工具不会将空页直接宣称为“全部历史已完整导出”。其他作者或作者未知的记录单独保留并计数。

### 页面显示重复页、重复游标、HTTP 错误或登录异常？

任务会停止，保留此前已成功保存的断点。回微博检查是否需要登录或验证，完成后重新连接再继续。若固定停在同一页，请提供脱敏错误信息反馈，不要反复快速请求。

### 关闭标签页、休眠或重启后会怎样？

当前请求可能中断，但成功提交到本地数据库的页仍会保留。重新连接后续传。采集中请保持工作台和微博标签页打开，后台节流可能使任务变慢。

### 能看评论和播放视频吗？

第一版只保留评论数量，不采集评论正文。视频使用接口返回的在线地址尝试播放，地址可能过期。HTML 中的图片也仍是在线引用，尚不是完整媒体离线备份。

### 长微博完整吗？

当前只保存列表接口返回的正文。带长文标记的记录在阅读器中显示“全文待核对”，暂未额外获取全文。

### 为什么导入后开始备份又从第一页开始？

导入用于保留、合并和阅读数据，不把外部文件的分页游标直接当成扩展采集断点。扩展会使用自己已经保存的断点；没有则从第一页读取，重复博文按 ID 合并。

### JSON 能不能反复导入？

原始备份 JSON 可以。阅读器“导出当前结果”的精简阅读数据暂不支持作为原始备份导入。建议始终保留工作台“下载 JSON”得到的原始文件。

### 数据会上传吗？

当前版本没有自建服务端、统计或同步。数据保存在扩展本地数据库和导出文件中。阅读器加载在线媒体时会访问对应媒体服务。卸载扩展可能清空数据库，请先导出。

### 怎么反馈问题？

打开 GitHub Issues，说明版本、Chrome 版本、操作步骤、预期结果和脱敏错误。不要提交 Cookie、密码、令牌、私人备份 JSON 或未打码截图。
