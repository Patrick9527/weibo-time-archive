01 / 开始之前

第一次使用？

  1. 点击“打开微博”，在微博自行登录。
  2. 在微博页面点击工具栏中的本扩展图标。
  3. 确认账号，点击“开始备份”。
  4. 结束后下载文件，双击 HTML 阅读。
02 / 已有备份

把已有 JSON 带进来

支持此前的分页备份及本工具的原始 JSON。多份同账号备份自动按博文 ID 合并。

导入后即可导出 HTML，无需连接微博。导入文件不作为采集断点；继续采集会从本工具已保存的断点或第一页开始。

这份备份包含什么

保存接口仍提供的博文、转发、发布时间、可见性和媒体地址。其他作者记录单独保留。

评论正文、长文补全与媒体文件下载尚未加入；图片和视频仍依赖在线地址。

接口没有后续内容只代表本轮读取结束，数量有差异时应继续核对，不能保证恢复全部历史。
