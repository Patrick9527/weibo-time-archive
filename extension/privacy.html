本地开发版 0.1

本工具非微博官方产品。当前版本没有自建服务器、统计追踪或云端同步，不上传账号凭据、博文或备份文件。

它会访问什么

当你在微博页面点击扩展图标时，工具读取当前登录账号的 UID、昵称及主页资料。开始备份后，在该页面发起只读请求，使用微博现有的登录状态读取账号仍可访问的博文。不会提取 Cookie、密码或验证码。

本地保存与导出

原始响应、博文和分页进度保存在扩展自己的 IndexedDB 中，按 UID 隔离。JSON 和 HTML 通过浏览器下载到本地。卸载扩展可能删除扩展内保存的数据，请先下载备份。更换 Chrome 用户配置不会自动转移档案。

在线媒体

工作台本身不加载微博媒体。打开档案阅读器后，头像、封面、图片和视频可能向对应在线媒体服务发起请求，服务方可以接收到网络请求及 IP 等信息。媒体未被离线下载，地址可能过期。

权限用途

activeTab、scripting：在你点击扩展时访问并执行随扩展打包的读取程序。
storage：保存当前连接的微博标签页信息。
unlimitedStorage：允许存放较大的本地档案，仍受设备可用空间限制。
downloads：保存用户生成的 JSON 和 HTML 文件。

功能范围

当前版本读取博文列表，包含接口返回的转发内容、媒体地址和可见性。评论正文、长文补全、媒体离线下载尚未实现。不绕过平台访问限制；验证码和访问异常时停止，用户自行回微博处理。
