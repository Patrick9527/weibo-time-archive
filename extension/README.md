# 微博时光档案 · v0.1.0

这是可直接安装的 Chrome 扩展文件夹。

1. Chrome 地址栏输入 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件夹，其中应直接包含 `manifest.json`。
4. 在微博网页登录后，点击工具栏的扩展图标，核对账号并开始备份。

不要双击 `index.html`。采集期间保持工作台和微博标签页打开。暂停后可以续传，关闭或重启后需要重新连接微博页面。

已有原始备份 JSON 可通过工作台导入、去重合并，再下载 JSON 或 HTML。文件通常位于 Chrome 下载目录的“微博时光档案/账号UID/”下，请到下载记录确认保存成功。

数据保存在扩展本地数据库中，没有上传服务。卸载可能删除数据库，请先导出。阅读器中的图片和视频仍引用在线地址，可能失效；评论正文、全文补全和媒体离线下载尚未支持。接口结束信号不保证历史完整。
