# 微博时光档案

**把自己的微博，保存成可以搜索、按时间翻阅的个人档案。**

Chrome 浏览器扩展。登录微博后点击备份，在本地生成 **原始 JSON** 和 **微博样式的独立 HTML**。不需要复制代码、Cookie 或密码，不需要搭建服务器。

> 当前是 **v0.1.0 早期试用版**，尚未上架 Chrome 扩展商店。接口仍可读取的内容可以尝试备份；不能恢复服务器不再提供的微博，也不能保证历史完整。

## 下载与安装

**普通用户请下载扩展 ZIP，无需安装 Node.js 或 Python：**

- **[下载 v0.1.0 扩展安装包](https://github.com/Patrick9527/weibo-time-archive/raw/refs/heads/main/downloads/weibo-time-archive-v0.1.0.zip)**
- [查看版本发布页面](https://github.com/Patrick9527/weibo-time-archive/releases)

1. 解压下载的 `weibo-time-archive-v0.1.0.zip`，得到 `weibo-time-archive-extension` 文件夹。
2. 在 Chrome 地址栏输入 **`chrome://extensions`**，按回车。
3. 打开右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择刚解压的文件夹。这个文件夹中应直接包含 `manifest.json`。
5. 点击 Chrome 工具栏的拼图图标，将 **微博时光档案** 固定到工具栏。

不要直接把 ZIP 拖进 Chrome，也不要双击 `index.html`。扩展必须通过上面的方式加载。请保留安装文件夹，移动或删除后可能无法正常使用。

如果你下载的是 GitHub 的 **Code → Download ZIP**，那是整个项目源码。解压后应选择其中的 **`extension`** 子文件夹进行安装。

详细步骤见 [安装指南](docs/INSTALL.md)。

## 开始备份

1. 打开 **[微博网页版](https://weibo.com/)**，自行登录。
2. **在微博页面点击扩展图标**，自动打开备份工作台。
3. 核对显示的账号昵称和 UID，点击 **开始备份**。
4. 保持工作台与微博标签页打开。工具每页间隔约 4 秒，逐页保存进度；可以暂停，再继续。
5. 读取结束后，默认自动提交 JSON 和 HTML 下载；也可以点击 **下载 JSON**、**下载 HTML**。
6. 在 Chrome 下载记录中确认文件已保存，双击 HTML 即可浏览。

文件通常保存在下载目录的 `微博时光档案/账号UID/` 下；Chrome 的下载设置可能要求你选择保存位置。

**重启浏览器后续传：** 重新打开微博并登录，在微博页面点击扩展图标，进入工作台后选择 **继续备份**。关闭标签页会停止当前采集，已成功保存的页面仍在扩展本地数据库中。

## 已有 JSON？直接生成 HTML

打开扩展工作台，点击 **选择 JSON 文件**。可一次选择多份同账号备份，自动去重合并，再点击 **预览档案** 或 **下载 HTML**。不同账号分别存储。

支持含 `pages[].response.data.list` 的分页备份，以及带 `uid` 或 `report.uid`、原始 `posts` 的合并备份。**阅读器“导出当前结果”生成的精简 JSON 暂不能重新导入。**

导入不覆盖扩展自己的采集断点；此前未在扩展中采集过的账号开始备份时会从第一页读取，并与已有数据合并。

## 可以做什么

- 自动识别当前登录账号，账号之间隔离保存。
- 备份原创、转发、仅自己可见内容，以及接口返回的时间、可见性、互动计数和媒体地址。
- 限速、暂停与断点续传，网络或权限异常时停止。
- JSON 保留原始数据；独立 HTML 内嵌阅读数据和脚本，无需扩展即可打开。
- HTML 支持正文及转发原文搜索、年份与月份导航、日期范围、正序/倒序、图片放大和在线视频播放。
- 导入、合并多份已有 JSON，再生成 HTML。

## 第一版的边界

| 内容 | 当前支持 |
| --- | --- |
| 博文列表与接口返回的正文 | 支持 |
| 转发及仍可见的原文 | 支持 |
| 仅自己可见博文 | 登录账号有读取权限且接口返回时支持 |
| 评论数量 | 保留接口返回值 |
| 评论正文、楼中楼 | 暂未支持 |
| 长微博全文补全 | 暂未支持；标记为待核对 |
| 图片、视频文件离线下载 | 暂未支持；目前引用在线地址 |
| 已删除、不可访问的内容恢复 | 不支持 |

**空页或无后续游标只代表接口结束信号。** 页面数量与接口总数可能不一致，不能据此宣称完整恢复。其他作者记录会保留并单独计数，不混入本人博文数。

## 数据与权限

当前版本没有服务端、追踪统计或云端同步。账号资料、博文和断点存放在扩展的本地 IndexedDB 中；不读取或上传密码、Cookie。卸载扩展可能删除本地数据库，**请先导出备份**。

权限：`activeTab` 和 `scripting` 用于用户点击后读取微博页面；`storage` 保存连接信息；`unlimitedStorage` 用于较大的本地档案；`downloads` 用于导出文件。没有所有网站的常驻访问权限。

**文字可离线阅读，在线媒体除外。** 打开阅读器时，图片、头像、封面和视频会访问相应媒体服务，在线地址可能失效。详见 [数据说明](docs/PRIVACY.md)。

## 开发与打包

项目无需第三方运行依赖。开发检查需要 **Node.js 18+**，打包需要 **Python 3.9+**。

```bash
node --test tests/extension.test.mjs
python3 tools/package.py
```

打包结果位于 `downloads/`，包含安装 ZIP 与 SHA-256 校验文件。修改 `extension/` 中的源码后，在 `chrome://extensions` 点击扩展卡片的重新加载；已打开的工作台也需要刷新。

```text
extension/       可直接加载的 Chrome 扩展源码
tests/           使用合成数据的自动测试
tools/           安装包生成脚本
docs/            安装、使用、数据与问题说明
downloads/       可安装 ZIP 与 SHA-256 校验文件
```

目前已有 13 项自动测试，覆盖分页、失败续传、重复数据、账号校验、导入和阅读器初始化；工作台及导出阅读器已进行浏览器查看。不同账号、Chrome 配置与平台接口变化仍需要持续验证。发布包不包含任何个人微博备份或登录信息。

本项目为个人档案工具，非微博官方产品。
